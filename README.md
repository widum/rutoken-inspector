# Rutoken Inspector

**Rutoken Inspector** — независимая диагностическая утилита для Windows, предназначенная для проверки подключённых криптографических USB-токенов и смарт-карт, просмотра общедоступной информации об устройствах, сертификатах и контейнерах **КриптоПро CSP**.

> **Неофициальное программное обеспечение.** Проект не разработан, не одобрен и не поддерживается производителями «Рутокен» и «КриптоПро». Упоминания торговых наименований используются для обозначения совместимых устройств и программных интерфейсов. Логотипы и исходный код производителей не входят в проект.

## Возможности

- Обнаружение смарт-карт и USB-токенов посредством доступных системных интерфейсов Windows.
- Определение считывателя, модели и версии устройства (там, где соответствующие сведения доступны).
- Диагностика доступности компонентов Rutoken COM Lite, PKCS#11 и CSP в средах x86/x64.
- Перечисление видимых КриптоПро CSP контейнеров, включая носители и `HDIMAGE`.
- Просмотр публичных объектов, сертификатов и диагностических данных там, где это поддерживается драйвером.
- Создание диагностических отчётов и просмотр журнала.
- Дополнительные пользовательские операции с **уже доступными** файловыми контейнерами: импорт из ZIP/папки, резервирование локального контейнера, проверка его структуры. Эти операции по запросу пользователя могут создавать файлы в его профиле.
- Штатная операция переноса контейнера средствами КриптоПро, только когда это допускается криптопровайдером и настройками ключа.

**Важно:** обнаружение устройства или наличие файлов `*.key` не подтверждает возможность автономной подписи. Приложение не заменяет штатную проверку сертификатов и криптографических операций средствами установленного провайдера. Оно не заявляет о поддержке извлечения неэкспортируемых ключей.

## Платформа

- Windows 10/11 x64.
- Go 1.23 или новее — для сборки из исходников.
- Отдельные диагностические функции требуют установленного драйвера, Rutoken COM Lite или КриптоПро CSP; они **не входят** в репозиторий.
- Тесты на физических устройствах и совместимость с различными моделями могут отличаться; наличие модели в описании не гарантирует поддержку всех операций.

## Сборка

На Windows выполните `BUILD_WINDOWS.bat`. Он сначала создаст 32-битный вспомогательный процесс, затем встроит его в приложение Windows x64.

Вручную в корне проекта:

```powershell
$env:GOOS='windows'; $env:GOARCH='386'; $env:CGO_ENABLED='0'
New-Item -ItemType Directory -Force assets | Out-Null
go build -trimpath -o assets/RutokenInspector_x86_worker.exe .
$env:GOARCH='amd64'
go build -trimpath -ldflags='-H=windowsgui' -o RutokenInspector3_v3.4.1_Win11.exe .
```

Наличие готового исполняемого файла в GitHub Actions означает успешную компиляцию, **не подтверждает** тестирование на токенах.
