# Roadmap

- Улучшение диагностики считывателей, PKCS#11 и Rutoken COM Lite.
- Более понятные отчёты о версиях драйверов и состоянии КриптоПро CSP.
- Улучшение интерфейса и устранение наложения элементов при изменении размера окна.
- Отдельная кнопка экспорта **обезличенного** отчёта без серийных номеров, сертификатных реквизитов и путей пользователей.
- Тесты на искусственных контейнерах без действительных закрытых ключей.
- Документирование совместимости разных моделей и конфигураций Windows.
- Проверка процедур резервного копирования только экспортируемых или уже доступных файловых контейнеров.
- GitHub Actions для проверки сборки x86/x64.

Планы не являются заявлением, что указанные возможности уже реализованы.
